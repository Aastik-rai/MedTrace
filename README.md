# MedTrace

AI-powered longitudinal patient health record and evidence retrieval platform.

## Vision

MedTrace transforms scattered medical records into a structured longitudinal patient history where every important fact can be traced back to its original medical evidence.

## Core Features

- Longitudinal patient timeline
- AI-powered medical record extraction
- Evidence-linked medical facts
- Patient history AI assistant
- Medical document management
- Medication history
- Laboratory trends
- Disease-specific history
- Record inconsistency detection

## Project Structure

- `frontend/` — Web application
- `backend/` — API and database
- `ai/` — AI and document processing
- `data/` — Synthetic/demo data
- `scripts/` — Utility scripts
- `docs/` — Documentation
- `tests/` — Testing
